# 社會安全制度｜公共財政第 11 章互動講義

Rosen & Gayer《Public Finance》（10th Global Edition）第 11 章 **Social Security** 的互動式講解網站（繁體中文）。

內容涵蓋：先修觀念（市場失靈、現值、逆選擇、道德風險）、為什麼需要社會安全、制度結構（隨收隨付、AIME/PIA、請領年齡、薪資稅）、所得重分配與信託基金、對儲蓄與退休行為的影響、人口老化的長期壓力，以及改革方案（永續償付、維持現制 vs 民營化），最後附重點摘要與 10 題小測驗。

全站共 26 張可操作的圖表，以 D3.js 繪製，支援深色模式與手機瀏覽。

- 圖 11.1、11.2、11.6 依課本圖形描點，為近似值。
- 標示「教學示意」的模擬（年金、死亡螺旋、蒙地卡羅、管理費等）使用簡化假設。

純靜態網站（HTML + CSS + JavaScript），直接以 GitHub Pages 發布。
